## 🍿 About the Project

Welcome to my personal portfolio, designed with inspiration from Netflix's streaming platform.

Instead of a traditional portfolio layout, I created an interactive streaming-style experience where visitors can explore my professional journey, technical skills, projects, education and achievements through a cinematic interface.

The portfolio represents my journey as an Artificial Intelligence and Machine Learning student and aspiring full-stack developer.

## 🚀 Getting Started

Follow these instructions to run the project locally.

### Prerequisites

* Node.js
* npm
* Git

### Clone the Repository

```bash
git clone https://github.com/veerendra-pampana/veerendra-streaming-portfolio.git
```

### Navigate to the Project

```bash
cd veerendra-streaming-portfolio
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal to explore the portfolio.

### Build for Production

```bash
npm run build
```
